════════════════════════════════════════════════════════════════════════════════
  GUIA RÁPIDO DE USO
════════════════════════════════════════════════════════════════════════════════

1. VALIDAR INTEGRIDADE LOCAL
   $ python3 scripts/validate_slot_map.py
   ✓ Esperado: "Validação OK: 161 números únicos..."

2. COPIAR CÓDIGO PARA GOOGLE APPS SCRIPT
   $ cat src/webapp/codigo.gs          # Backend
   $ cat src/webapp/Album.html         # Interface
   $ cat src/webapp/Index.html         # Login

3. EXECUTAR RECONCILIAÇÃO NO APPS SCRIPT
   - reconciliarFigurinhas()   (2-5 min) - sincroniza figurinhas do Drive
   - reconciliarTemplates()    (2-5 min) - aplica compartilhamento público

4. TESTAR NO NAVEGADOR
   - Login: autenticar com conta
   - Navegação: Capa → Agências A-Z → Comissão Técnica → Contracapa
   - Drag-and-drop: arrastar figurinha para slot
   - Inventário: scroll horizontal com setas ‹ ›
   - Pacotes: rasgar e sortear 5 figurinhas
   - Duplicatas: trocar 5+ repetidas
